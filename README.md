# TuneFlow is Music Player
A modern, responsive music player built with HTML, CSS, and Vanilla JavaScript.

## ✨ Features
- Play / Pause / Next / Previous
- Smooth progress bar
- Shuffle & Repeat modes
- Volume control & mute
- Playlist system
- Fully responsive design

## 🛠 Technologies
- HTML5
- CSS3 (Flexbox, Variables)
- Vanilla JavaScript
